# Getting unstuck, now

Procrastination is mostly **short-term mood repair** (Sirois & Pychyl). The task
brings up a bad feeling, and avoiding it brings relief, so the avoidance is
rewarded and repeats. Discipline doesn't break that loop. What breaks it is
dealing with the **feeling** and the **size of the first step**. The mechanism
is in [emotion-regulation.md](references/emotion-regulation.md).

## How to run it

Short replies, one question at a time. The goal is a single next action,
**started**, not a plan. Don't lecture and don't list ten tips.

## The five-minute sequence

1. **Name it.** "This task makes me feel ___ because it's ___." Match it
   against the table below. Naming the feeling takes some of its force away.
2. **Shrink it.** The next **physical** action, so small it's absurd to refuse,
   under two minutes: "Open the doc and type one bad sentence."
3. **Lower the bar.** Give explicit permission to do it badly. Label it
   `DRAFT 0`. Done badly beats not done.
4. **Start a short clock.** Ten minutes only, with real permission to stop
   afterwards. Starting is the hard part. Keep the permission honest: if they
   stop at ten, that still counts.
5. **Forgive yesterday.** If time was lost, say so in one sentence and move on.
   Students who forgave themselves for procrastinating on one exam procrastinated
   less on the next (Wohl, Pychyl & Bennett, 2010).

## What the task is like → what to do

| The task is…              | Try                                                                     |
| ------------------------- | ----------------------------------------------------------------------- |
| Boring                    | temptation bundle (a podcast only while doing it), timer race           |
| Frustrating               | stop at the frustration point, write the question, ask someone          |
| Difficult                 | break off the smallest piece that can be finished today                 |
| Ambiguous                 | write "done means…" and "the first step is…" before anything else       |
| Unstructured              | make a three-line checklist, then do line one                           |
| Not personally meaningful | `akrasia-contrast`: link it to a wish, or decide to drop or delegate it |
| Not rewarding             | set a small reward for after the ten minutes                            |

These seven task traits come from Pychyl's work. More stuck patterns
(perfectionism, overwhelm, "productive" procrastination) are in
[stuck-patterns.md](references/stuck-patterns.md).

## Then

Once the ten minutes have started, hand over to `akrasia-focus` for the rest of
the session. If this is the third time this week, suggest `akrasia-commit`: a
pattern needs a device, not another rescue.
