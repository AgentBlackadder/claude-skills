# Weekly review template

Copy this and fill it in. The prompts in _italics_ are what Claude asks, one at a
time. Twenty minutes. If it takes longer, the review has become a planning
session in disguise. Stop and use `akrasia-plan`.

```
WEEK OF: ____________

1. COLLECT
   Plans written this week:            ___ of ___ days
   Focus sessions logged:              ___  (total focused minutes: ___)

2. SCORE: the ONE THING
   Mon ☐  Tue ☐  Wed ☐  Thu ☐  Fri ☐  (Sat ☐  Sun ☐)
   Hit rate: ___ / ___

3. CAUSE OF EACH MISS (one per miss)
   Day | ONE THING | Cause (over-planned / no first action / focus leak /
                            avoidance / external) | Detail
   ___ | _________ | ______________________________ | ______________

   Cause that repeats: ______________________

4. CALIBRATE
   Tasks with an estimate and an actual:   ___
   Median ratio (actual ÷ estimated):      ___
   Last week's ratio:                      ___

5. LAST WEEK'S EXPERIMENT
   What it was:           ______________________
   Did it run?            yes / partly / no
   Effect on the cause?   better / same / worse / can't tell
   Decision:              keep / adjust / drop

6. THIS WEEK'S ONE EXPERIMENT
   Aimed at cause:        ______________________
   The change:            ______________________
   How I'll know:         ______________________

7. ONE THING I'M PLEASED WITH
   ______________________
```

## Prompts, one at a time

1. _"Let's look at what happened, not how you feel about it yet. What were the
   ONE THINGs this week, and which got done?"_
2. _"For each one that didn't, what happened right before? Pick the closest
   cause from this list."_
3. _"Which cause came up more than once?"_
4. _"Do you have any tasks where you know both the estimate and how long it
   took?"_
5. _"Last week's experiment was ___. Did it run? Did it change anything?"_
6. _"Given the repeating cause, what's one change for this week?"_ Offer two or
   three options from the skills, and let the user choose.
7. _"What's one thing from this week you're pleased with?"_ Always ask this.
   The doer needs a reason to keep turning up.

## Reading the results

| Pattern                                   | Likely cause          | Experiment to try                                     |
| ----------------------------------------- | --------------------- | ----------------------------------------------------- |
| misses cluster late in the week           | over-planning, fatigue | lighter Thu/Fri plans; ×ratio on estimates           |
| misses cluster on meeting-heavy days      | no protected block    | book the focus block in the calendar like a meeting   |
| the same task missed three or more times  | avoidance or low value | `akrasia-unstick` on it, then `akrasia-contrast`     |
| sessions start but urges run high         | focus leak            | distraction audit, then friction or a hard block      |
| no plans written on some days             | the planning step itself | plan the night before, attached to an existing habit |
| everything done every day                 | under-planning        | a harder ONE THING, or one more task                  |

## Fresh starts

People are more likely to start on goals at temporal landmarks: a new week,
month or birthday (Dai, Milkman & Riis, 2014). The weekly review falls on one
deliberately. Use it: frame the new week as a clean page, and let last week's
misses stay last week's.
