# If-then library

Ready-made implementation intentions. Treat them as starting points only. The
best if-then uses the user's own cue in the user's own words, so adapt each
one to the moment the user describes before using it.

**Pattern:** _If <a cue you can notice>, then I will <one concrete action>._

A good cue is something you'd notice happening: a feeling, a time, a place, a
thought. A good action can start in seconds and doesn't depend on mood.

## Focus: drifting mid-task

| If…                                             | then I will…                                                              |
| ----------------------------------------------- | ------------------------------------------------------------------------- |
| I feel the pull to open a new tab               | write the urge on the capture list and finish the current sentence        |
| I reach for my phone                            | put it face down in the other room and come back to the last line I wrote |
| a paragraph gets hard and I want to switch      | write the question I'm stuck on in one line, then answer it badly         |
| I remember something I must do                  | write it on the capture list, not do it                                   |
| I notice I've been reading for 10 minutes instead of writing | close the source and write what I remember                    |
| a notification sound goes off                   | not look until the timer ends                                             |

## Starting: the moment before

| If…                                        | then I will…                                              |
| ------------------------------------------ | --------------------------------------------------------- |
| it's 9:00 and I'm at my desk               | open the file for the ONE THING before any other window   |
| I catch myself saying "after I check email" | do the two-minute first action first                     |
| I feel dread about the task                | name the feeling out loud, then set a 10-minute timer     |
| I don't know where to start                | write "the next physical action is…" and finish the sentence |
| I sit down after lunch                     | re-read the parking note from this morning                |

## Avoidance: perfectionism and fear

| If…                                        | then I will…                                                          |
| ------------------------------------------ | --------------------------------------------------------------------- |
| I think "it has to be good"                | write the worst possible version first, labelled DRAFT 0              |
| I want to research "a bit more"            | write what I'd say now and mark the gaps with [TK]                    |
| I imagine someone judging it               | picture sending it to the one friendly reader instead                 |
| I finish a small piece and want to celebrate by stopping | note what's next, then take a five-minute break, not an open one |

## Shallow work and switching

| If…                                          | then I will…                                                     |
| -------------------------------------------- | ---------------------------------------------------------------- |
| a message arrives during a focus block       | leave it until the shallow window                                |
| I'm tempted to "quickly" reply               | add it to the capture list with the name of who to reply to     |
| I have to switch tasks for a real reason     | write a one-line parking note: where I stopped, what's next     |

## End of day

| If…                                   | then I will…                                                   |
| ------------------------------------- | -------------------------------------------------------------- |
| it's shutdown time                    | write tomorrow's ONE THING and its first action, then close the laptop |
| I didn't do the ONE THING             | write one line on why (the cause, not a judgement) for the review |

## Writing a new one

1. Ask: "What exactly happens right before it goes wrong?" That moment is the
   cue.
2. Ask: "What's the smallest thing you could do at that moment instead?" That's
   the action.
3. Say it back in one sentence and check the user would recognise the cue if
   it happened.
4. Test it for a week, then keep it, adjust it or drop it in the review.
